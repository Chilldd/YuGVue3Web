# 页面设计风格

整体采用「高级暗黑未来感（Premium Dark Futuristic UI）」设计风格。

主色调：
- 背景主色：#1A1A1D
- 品牌强调色：#E6397C
- 辅助高亮色：#FF5C9D
- 文字主色：#FFFFFF
- 次级文字：rgba(255,255,255,0.65)
- 分割线：rgba(255,255,255,0.08)

整体视觉关键词：
高级、沉浸、克制、未来感、玻璃拟态、柔和光晕、丝滑动画、电影感、科技感、轻奢、极简。

页面特点：
- 大面积深色留白
- 使用柔和粉色霓虹光晕
- 局部玻璃拟态（Glassmorphism）
- 卡片半透明 + backdrop blur
- 边框极淡且带微弱发光
- 阴影柔和，不厚重
- 强调空间感与层次感
- 使用渐变与环境光增强氛围
- UI布局呼吸感强，不拥挤

动画规范：
- 所有动画必须丝滑、缓动自然
- 使用 ease / ease-in-out
- 动画时长控制在 0.3s ~ 0.8s
- Hover 时轻微上浮（translateY）
- 使用柔和发光扩散
- 禁止夸张弹跳动画
- 页面进入动画采用 fade + translateY
- 背景增加慢速漂浮粒子与动态光效
- 鼠标交互带微弱跟随感

组件风格：
按钮：
- 圆角偏大（14px~20px）
- 粉色渐变背景
- Hover 有光泽扫过效果
- Hover 时轻微发光和浮起

按钮颜色规则（按优先级）：
1. 删除、取消关联等影响大的操作 → `type="error"`（红色）
2. 状态切换为禁用/停用 → `type="warning"`（黄色）
3. 状态切换为启用/激活 → `type="success"`（绿色）
4. 其余按钮保持默认样式，不使用彩色

输入框：
- 深色半透明背景
- 聚焦时粉色 glow
- 极简边框
- 圆角柔和

卡片：
- 使用玻璃拟态
- 背景 rgba(255,255,255,0.03)
- backdrop-filter: blur(20px~40px)
- 带超浅边框
- 带环境光阴影

图表/数据区：
- 深色科技感
- 使用柔和发光折线
- 不使用高饱和颜色
- 强调高级感而非炫彩

布局规范：
- 使用大圆角
- 间距宽松
- 强调纵向节奏
- 内容居中对齐
- 避免复杂边框和大量线条

禁止：
- 廉价霓虹风
- 高饱和赛博朋克
- 花哨渐变
- 过度动画
- 强烈描边
- 拥挤布局
- 五颜六色
- Material Design 风格
- 传统后台管理风格

整体参考风格：
Linear + Raycast + Vercel + 苹果发布会页面 + 高级游戏UI + 科幻电影HUD。

输出要求：
- 页面必须具有高级感和品牌感
- 视觉统一
- 动效高级且克制
- 具有现代 SaaS 产品质感
- 适合高端 AI 平台 / 数据平台 / Web3 / 智能系统

要求视觉达到 Dribbble 高赞作品级别，具有真实产品落地感，而不是概念稿。
